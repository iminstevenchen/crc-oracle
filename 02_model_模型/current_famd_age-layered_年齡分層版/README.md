## FAMD 版本（v3-famd）

線性 PCA 版把 T/N/M 分期、分化程度這類類別變數，人工映射成有序數值
（例如 T4a=4、T4b=4.5）才丟進標準 PCA。這個做法簡單好懂，但隱含假設
「類別之間的數值距離有意義」——對本來就無序或非等距的分期代碼不完全合理。

**FAMD（Factor Analysis of Mixed Data）** 讓 11 個連續變數走 PCA 的邏輯，
12 個類別變數（性別、TNM/T/N/M分期、腫瘤側別、分化程度等）保留真正類別標籤，
用類似 MCA 的指標矩陣/卡方距離編碼，數學上更適合這種連續+類別混合的臨床資料。
特徵仍是同一套 23 個。

### 結果

| 項目 | 線性PCA版 | FAMD版 |
|---|---|---|
| 前3軸累積解釋變異 | 39.6% | 24.2%（見下方說明，兩者計算基準不同，不能直接比大小）|
| 訓練集 C-index | 0.7972 | 0.7993 |
| **5-fold CV C-index** | **0.7962** | **0.7978** |
| held-out 12例 C-index | 0.7568 | 0.7568 |

FAMD 版 Cox 模型（類別變數改用 one-hot 而非人工序數編碼）C-index 略高一點點，
在統計上算是同一水準，沒有戲劇性差異——這符合預期，因為兩版本本來就是同一批
臨床資訊，差別只在「類別變數怎麼進降維空間」。

> **關於解釋變異百分比不能直接比較**：FAMD 的變異分解分母包含類別變數展開後的
> 指標矩陣總慣性（inertia），類別數愈多、分母天生愈大，所以同樣訊息量算出來的
> 累積百分比會比線性 PCA 低，這是計算基準不同，不代表 FAMD 抓到的資訊比較少。

主成分載荷解讀（`column_contributions_`，看貢獻度而非方向）：
- **PC1**：TNM總分期、M分期、根治性切除、N分期、淋巴結比率、T分期 → 跟PCA版一樣是**腫瘤/淋巴結負擔＋手術根治性軸**
- **PC2**：TNM總分期、T分期、環周侵犯、血色素、腫瘤側別、白蛋白 → **分期細節＋侵犯程度＋營養軸**
- **PC3**：TNM總分期、N分期、腫瘤側別、切除margin、T分期、淋巴結比率 → **分期細節＋側別＋margin軸**

### 相似病患查詢：跟PCA版demo比較

同一個查詢（68歲男性、第二期、T2N0M0、右側大腸、中分化腺癌、根治性擇期手術、CEA 12.5）：

| 年 | PCA版 cohort OS | FAMD版 cohort OS | 全體 OS |
|---|---|---|---|
| 1年 | 99.0% | 92.0% | 93.0% |
| 3年 | 92.6% | 86.5% | 79.2% |
| 5年 | 85.3% | 81.1% | 69.8% |
| 10年 | 76.0% | 61.3% | 56.3% |

兩版都比全體病患存活率好（方向正確），但 **FAMD 版圈出來的族群，腫瘤側別
（site_group）沒有像 PCA 版那麼集中在「右側」**（100人中約半數是左側）——
這是因為 FAMD 用指標矩陣/卡方距離編碼類別變數時，每個類別的權重會被
「該類別在母體中的相對頻率」影響，稀有或均勻分布的類別（如側別三分類）
在整體5維距離裡的權重，跟人工指定的PCA距離不會完全一樣。
這不是bug，是兩種方法本質上對「相似」的定義不同：
- PCA版：你（人工）決定每個類別間的數值距離，帶有較強的臨床假設
- FAMD版：距離由資料本身的類別分布統計決定，較「資料驅動」但不保證跟臨床直覺一致

**建議**：如果你們要的「相似」偏向臨床直覺（例如腫瘤側別、分期一定要優先匹配），
線性PCA版（配合人工挑選的序數編碼）可能更貼近醫師的期待；如果要的是統計上
更嚴謹、不隨意假設類別距離的降維方法，FAMD版更站得住腳。也可以考慮混合做法：
用FAMD降維，但KNN距離計算時對PC1（腫瘤負擔軸）加權放大，讓分期/側別這類
臨床上最重要的因子在相似度計算中佔更大比重。

## 相似病患數量(K)：自適應搜尋邏輯

`similarity_api.py` / `similarity_api_famd.py` 的 `build_response()` 現在預設用
**「SD半徑起點 + 事件數門檻自動擴張」**取代原本固定 K=100：

1. 把PCA/FAMD各軸依訓練集自己的標準差正規化，變成「SD單位」的合併距離
   （這樣0.5 SD在任何查詢下都有一致的統計意義，不會被某一主成分變異數特別大而扭曲）
2. 以 `sd_start=0.5` 為起始半徑收案，若累積死亡事件數 < `min_events`(預設20)，
   自動擴大半徑（等同擴大K），直到達標或碰到 `k_max`(預設300) 為止
3. 收案人數永遠介於 `[k_min, k_max]`（預設 `[30, 300]`）之間
4. 若擴到 k_max 都還不夠事件數，回傳 `low_confidence=True`——代表這是資料庫裡的
   罕見病患組合，前端應該用醒目的方式標示「相似病例過少，結果僅供參考」，
   而不是照樣呈現一條看起來很篤定的KM曲線

**為什麼不能直接用「0.1~0.5 SD」當固定門檻**：PCA/FAMD空間是5維的，任兩個隨機病患的
期望距離約是 √5 ≈ 2.24 SD（維度詛咒），實測 0.1 SD 半徑找到 **0 個病患**、0.3 SD 只有
11人，只有到 0.5 SD 才開始有意義（demo query算出90人/20事件，剛好跟事件數門檻法的
K=91幾乎一致）。所以與其寫死一個SD數字，讓它依事件數動態擴張才穩健。

用法：
```python
from similarity_api import build_response

# 預設：自適應搜尋
payload = build_response(demo_query)
print(payload["cohort"]["search"])
# {'method': 'adaptive_sd_event', 'k_used': 90, 'sd_radius_used': 0.499,
#  'n_events': 20, 'low_confidence': False, ...}

# 需要跟舊結果比較時，仍可用固定K
payload_fixed = build_response(demo_query, k=100)
```
前端請務必把 `payload["cohort"]["search"]["low_confidence"]` 和 `n_events`
顯示出來（或至少在低信心時跳出提示），這是保護醫師不被過度自信的曲線誤導的關鍵欄位。

## 【v3.1更新】年齡改用5分層類別變數

Team討論後認為年齡對存活率的實務影響很重要，原本想直接假設「年齡越小、存活權重越高」
做線性調整。我們先用資料驗證了這個假設，結果**跟直覺不完全一樣**：

實測5年存活率（依你們指定的5個分層）：

| 年齡層 | 5年存活率 | 調整後風險(以<50為基準，控制其他22變數) |
|---|---|---|
| <50 | 74.2% | 基準 |
| 50-60 | 76.8% | HR=0.86（風險反而較低，p<0.0001） |
| 60-70 | 76.3% | HR=0.93（風險反而較低，p=0.04） |
| 70-80 | 65.5% | HR=1.35（風險較高，p<0.0001） |
| **80+** | 45.3% | **HR=2.26（風險最高，p<0.0001）** |

**50-70歲風險反而比<50歲低**，不是線性遞減關係——這是大腸直腸癌領域已知的現象：
早發型大腸癌（<50歲確診）腫瘤生物學通常較惡性，即使控制分期後，獨立風險仍略高於
中年族群。因此我們**沒有**採用「<50最高權重、依年齡遞減」的線性假設，改用資料實測
的風險結構：50-60/60-70風險最低、<50居中、70-80較高、80+最高。

**實作方式**：把年齡從連續變數改成 `age_group` 這個5分層類別變數
（`<50` / `50-60` / `60-70` / `70-80` / `80+`），跟其他12個類別變數一樣用FAMD的
指標矩陣編碼方式處理（原本連續變數11個→10個，類別變數12個→13個，特徵總數仍是23個）。

**效果**：5-fold CV C-index 從 0.7978 提升到 **0.7995**（小幅但真實的提升，因為類別
分組能捕捉「50-70歲比<50歲風險更低」這種連續線性年齡變數抓不到的非線性關係）。

**API使用方式不變**：`similarity_api_famd.py` 的 `build_response()` 仍然接受
`AGE=68` 這種原始年齡數字，內部會自動轉換成對應的年齡分層，NLP解析層不需要改動。
也可以直接傳 `age_group="70-80"` 這種字串，兩種寫法等效。

**注意**：age_group在FAMD無監督降維（PC1-3）裡的貢獻度依然不高（PC1排名19/23），
這點跟之前討論的一樣——FAMD/PCA是無監督方法，不知道存活結果，年齡在Cox模型（有監督、
直接預測存活）裡才會顯示出它真正的預後權重。這兩件事本來就不是同一回事，不用因為
FAMD貢獻度低就懷疑年齡沒被用上。
