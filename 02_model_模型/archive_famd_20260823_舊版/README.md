# 腸命天機 Gut Instinct · PCA v3 訓練結果與串接說明

## 資料
- 來源：`癌症資料20072023_AI去識別擬真版_v2_part{1,2,3}.xlsx`（合併後 12,250 筆、197 欄，與原始 CSV 一致）

- 剔除 42 筆追蹤時間 ≤ 0 天（同日出入院、無真實追蹤資訊）的病例，訓練集實際 n = 12,196

## 特徵（23 個，比 v2 試跑版的 16 個更完整）
在原本 16 個特徵（年齡、性別、分期、腫瘤位置、分化程度、手術術式等）的基礎上，
新增了 T/N/M 細分期、淋巴結陽性比率、腫瘤外觀與大小、環周侵犯、切除margin、
手術根治性/時機、CEA/白蛋白/血色素等術前檢驗值，詳見
`artifacts/pca_coefficients_v3.json` 的 `features` 欄位（含中文標籤）。

> 這 23 個特徵是我依照大腸直腸癌預後文獻常見的預後因子重新挑選、工程化的結果，
> **不是延用文森/Sean 那邊既有的固定清單**——如果他們已經有明確的 23 欄位定義，

## 串接方式（Python 端）
```python
from similarity_api import build_response

payload = build_response({
    "AGE": 68, "SEX": 1, "TNM_stage": 2, "T_stage": 2,
    "N_stage": 0, "M_stage": 0, "site_group": 0,   # 0=右側大腸

    "IR_curative": 1, "OT_emergency": 0,
    "LAB_CEA_log": 2.60269,                          # log1p(12.5)

# payload["risk_score"]    CoxPH 相對風險分數
```

關鍵預後因子放進去，導致 PCA 空間裡「相似」的定義跟臨床認知不一致；v3 加入這些後
應該會明顯改善。

## FAMD 版本（v3-famd）

線性 PCA 版把 T/N/M 分期、分化程度這類類別變數，人工映射成有序數值
（例如 T4a=4、T4b=4.5）才丟進標準 PCA。這個做法簡單好懂，但隱含假設
「類別之間的數值距離有意義」——對本來就無序或非等距的分期代碼不完全合理。

**FAMD（Factor Analysis of Mixed Data）** 讓 11 個連續變數走 PCA 的邏輯，
12 個類別變數（性別、TNM/T/N/M分期、腫瘤側別、分化程度等）保留真正類別標籤，
用類似 MCA 的指標矩陣/卡方距離編碼，數學上更適合這種連續+類別混合的臨床資料。
特徵仍是同一套 23 個。

### 結果

| 項目 | 線性PCA版 | FAMD版 |
|---|---|---|
| 前3軸累積解釋變異 | 39.6% | 24.2%（見下方說明，兩者計算基準不同，不能直接比大小）|
| 訓練集 C-index | 0.7972 | 0.7993 |
| **5-fold CV C-index** | **0.7962** | **0.7978** |
| held-out 12例 C-index | 0.7568 | 0.7568 |

FAMD 版 Cox 模型（類別變數改用 one-hot 而非人工序數編碼）C-index 略高一點點，
在統計上算是同一水準，沒有戲劇性差異——這符合預期，因為兩版本本來就是同一批
臨床資訊，差別只在「類別變數怎麼進降維空間」。

> **關於解釋變異百分比不能直接比較**：FAMD 的變異分解分母包含類別變數展開後的
> 指標矩陣總慣性（inertia），類別數愈多、分母天生愈大，所以同樣訊息量算出來的
> 累積百分比會比線性 PCA 低，這是計算基準不同，不代表 FAMD 抓到的資訊比較少。

主成分載荷解讀（`column_contributions_`，看貢獻度而非方向）：
- **PC1**：TNM總分期、M分期、根治性切除、N分期、淋巴結比率、T分期 → 跟PCA版一樣是**腫瘤/淋巴結負擔＋手術根治性軸**
- **PC2**：TNM總分期、T分期、環周侵犯、血色素、腫瘤側別、白蛋白 → **分期細節＋侵犯程度＋營養軸**
- **PC3**：TNM總分期、N分期、腫瘤側別、切除margin、T分期、淋巴結比率 → **分期細節＋側別＋margin軸**

### 相似病患查詢：跟PCA版demo比較

同一個查詢（68歲男性、第二期、T2N0M0、右側大腸、中分化腺癌、根治性擇期手術、CEA 12.5）：

| 年 | PCA版 cohort OS | FAMD版 cohort OS | 全體 OS |
|---|---|---|---|
| 1年 | 99.0% | 92.0% | 93.0% |
| 3年 | 92.6% | 86.5% | 79.2% |
| 5年 | 85.3% | 81.1% | 69.8% |
| 10年 | 76.0% | 61.3% | 56.3% |

兩版都比全體病患存活率好（方向正確），但 **FAMD 版圈出來的族群，腫瘤側別
（site_group）沒有像 PCA 版那麼集中在「右側」**（100人中約半數是左側）——
這是因為 FAMD 用指標矩陣/卡方距離編碼類別變數時，每個類別的權重會被
「該類別在母體中的相對頻率」影響，稀有或均勻分布的類別（如側別三分類）
在整體5維距離裡的權重，跟人工指定的PCA距離不會完全一樣。
這不是bug，是兩種方法本質上對「相似」的定義不同：
- PCA版：你（人工）決定每個類別間的數值距離，帶有較強的臨床假設
- FAMD版：距離由資料本身的類別分布統計決定，較「資料驅動」但不保證跟臨床直覺一致

**建議**：如果你們要的「相似」偏向臨床直覺（例如腫瘤側別、分期一定要優先匹配），
線性PCA版（配合人工挑選的序數編碼）可能更貼近醫師的期待；如果要的是統計上
更嚴謹、不隨意假設類別距離的降維方法，FAMD版更站得住腳。也可以考慮混合做法：
用FAMD降維，但KNN距離計算時對PC1（腫瘤負擔軸）加權放大，讓分期/側別這類
臨床上最重要的因子在相似度計算中佔更大比重。
