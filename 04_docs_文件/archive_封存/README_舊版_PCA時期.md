# 腸命天機 Gut Instinct · 相似病患智慧查詢（UI/UX 雛形）

大腸直腸癌 AI 輔助判斷的前端雛形，實作陳繹中醫師「最簡單的 UI」構想：
**自然語言輸入 → 自動解析欄位 → 醫師確認 → 相似族群結果**。

## 兩個版本
- **`index_整合版.html`（推薦，開會用）** — 我的自然語言前端**串接組員的真實 PCA/KM 引擎**。輸入病患→真實 KNN 從 12,250 位病患找最相似的 K 位→真實 Kaplan–Meier 存活率。所有數字都是真的（1/3/5 年 OS、CI、族群統計）。
- **`index.html`（純前端 demo）** — 同樣的三步流程與畫面，但用內嵌/模擬資料，適合單純展示 UI/UX 動線。

兩個都是單檔、離線可用，直接用瀏覽器打開，無需安裝或連網。

## 整合版怎麼串的
`parseNL()` 把病患敘述解析成結構化欄位 → 寫入隱藏表單 → 呼叫組員引擎原封不動的 `projectPatient()`／`cohort()`（KNN）／`km()`（Kaplan–Meier）→ 用我的 UI 呈現真實結果。引擎程式碼完全沒改，只是換了個自然語言的前端在前面。誠實數字：PCA 只存前 3 個主成分＝累積解釋變異 34.4%（非模擬版的 90.8%）。

## 三步流程
1. **輸入區** — 一句話描述病患（例：「68歲男性，第二期升結腸癌，中分化腺癌，elective curative surgery，CEA 12.5，希望找 100 位相似病患」）。附範例可一鍵帶入。
2. **解析與確認** — 規則式 NLP 解析出年齡、性別、期別、位置、病理、分化、手術目的/時機、CEA、相似病患數，每欄標示「AI 解析／預設」，可直接修改，再按「確認並執行」。
3. **相似族群結果**
   - Selection 摘要 KPI：候選族群、PCA 主成分數、解釋變異、選定族群人數、中位 PCA 距離
   - Index patient 與 selected cohort 對照表（中位數 + IQR、比例）
   - Kaplan–Meier 存活曲線（OS / CSS / DFS 可切換，含 95% CI 陰影）
   - PCA 前三主成分的臨床意義說明

## 資料來源
- KM 存活曲線用的是**真實的 landmark 數字**，取自 `Stage_I-IV_OS_DFS_CSS_1_3_5年.xlsx`（各期別 1/3/5 年估計與 CI），內嵌於頁面。
- 相似族群的分布為依 index patient 種子產生的合理模擬（示範用），對接後端後即可換成真實計算。

## 已知限制（沿用 PCA 分析報告）
目前底層是 AI 去識別合成資料，去識別破壞了欄位間臨床關聯，期別與存活相關性偏低，**存活數字僅供方法學／流程示範，不可用於臨床判讀**。整條管線正確，接上原始資料庫即可產出具臨床意義的結果。頁面已明確標註此限制。

## 對接後端的建議切點
`parseNL()` 輸出的結構化條件即為送往查詢引擎的 payload；`buildCohort()` 為模擬，替換成真實 PCA/KNN 查詢即可。可再前接一層 LLM 強化口語解析，計算仍由統計程式執行以確保可稽核。
