# 腸命天機：Project CRC-ORACLE

> **Real-World Intelligence for Personalized Colorectal Cancer Outcomes**
> 大腸直腸癌相似病患智慧查詢 — 用一句自然語言描述病患，找出資料庫中最相似的一群病患並給出存活與術後結果。

**線上 Demo：** https://gut-instinct.vercel.app

StanCode 201 專題。醫師以自然語言輸入臨床特徵，系統依官方 codebook 轉為結構化變數，透過主成分分析（PCA）進行降維與相似族群分層，再以 Kaplan–Meier 呈現存活結果。

## 功能
- **自然語言輸入（中／英）**：一句話描述病患，系統自動解析為官方 codebook 的變數與代碼（如 升結腸 → `TL_1 = 2`），醫師確認後執行。未提及的條件顯示「未指定」、以中位數代入，不假設預設值（僅病理型態、手術目的、手術時機保留預設）。
- **變數對應驗證表**：列出每個輸入詞對到的變數／代碼／中英文，供醫師核對指向。
- **相似族群（PCA）**：將病患投影到 PC1–PC3 空間，取距離最近的族群作為對照。
- **存活與術後結果**：Kaplan–Meier 曲線（Greenwood 95% CI）、1／3／5 年存活率、**30 天手術死亡率**、**中位術後住院天數**（出院日 − 開刀日）。
- **視覺化**：目標病患 vs 相似族群對照表、KM 曲線、PCA 主成分散布圖。

## 怎麼用
1. 在輸入框打一句病患描述，例如：
   `68歲男性，第二期升結腸腺癌，中分化，前位切除，CEA 12.5，找 100 位相似病患`
2. 按「解析條件」，確認欄位（可修改）後按「確認並執行」。
3. 看結果：Selection 摘要、對照表、Kaplan–Meier 曲線與術後結果、PCA 散布圖。

## 資料版本與重要限制
目前使用 **v2 去識別擬真資料**（剔除 12 例測試病例，納入 12,194 位）。期別分層已呈合理臨床分離（第 I 期 5 年 OS ~89%、第 IV 期 ~23%），但仍為去識別擬真資料，**僅供方法學與研究示範，不可作為臨床判讀或投稿依據**。

> 註：網站內嵌的 PCA/存活結果為 Steven 的獨立試跑版（16 特徵）。官方分析以 Kevin／Sean 的 v3（23 特徵、Cox C-index ~0.79、held-out 12 例）為準，待官方版定案後取代。
