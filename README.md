# 腸命天機 Gut Instinct

> 大腸直腸癌 AI 輔助判斷系統 — 用一句自然語言描述病患，找出資料庫中最相似的一群病患並給出存活預測。

**線上 Demo：** https://gut-instinct.vercel.app

StanCode 201 專題。以真實世界的大腸直腸癌登記資料為基礎，協助醫師從「病患特徵」快速找到相似族群與存活參考。

---

## 功能

- **自然語言輸入**：醫師用一句話描述病患（年齡、期別、位置、病理、分化、手術、CEA…），系統自動解析成結構化欄位，不需逐欄填寫。
- **解析確認**：執行前先顯示解析結果讓醫師確認、可修改，降低誤判。
- **真實相似族群（KNN）**：把病患投影到 PCA 主成分空間，從 12,250 位病患中取距離最近的 K 位。
- **真實存活分析**：對相似族群計算 Kaplan–Meier 存活曲線（含 Greenwood 95% CI）與 1/3/5 年存活率。
- **視覺化**：目標病患 vs 相似族群對照表、KM 曲線、PCA 主成分散布圖。

## 怎麼用

1. 在輸入框打一句病患描述，例如：
   `68歲男性，第二期升結腸癌，中分化腺癌，elective curative surgery，CEA 12.5，希望找 100 位相似病患`
2. 按「解析條件」，確認欄位無誤後按「確認並執行」。
3. 看結果：Selection 摘要、對照表、Kaplan–Meier 曲線、PCA 散布圖。

## 技術架構

單一檔案的靜態網頁，無需後端：自然語言解析、PCA 投影、KNN、Kaplan–Meier 計算與繪圖全部在瀏覽器端完成。

```
一句話描述 → 規則式解析 → 結構化欄位 → PCA 投影 + KNN 相似族群 → Kaplan–Meier → 前端呈現
```

此設計讓「口語輸入」與「可稽核的統計計算」分離：語言層可隨時替換為更強的模型，計算仍由統計程式負責。

## 資料來源與重要限制

目前使用「癌症資料20072023_AI 去識別合成版」。去識別合成過程會破壞欄位間的臨床關聯（期別與死亡相關係數約 0.02，主要保留訊號的是年齡），因此**網站上的存活數字僅供方法學與流程示範，不可作為臨床判讀或投稿依據**。整條分析管線（清理、TNM 還原、PCA、KNN、Kaplan–Meier、信賴區間）已完整正確，接上關聯完整的原始資料庫即可產出具臨床意義的結果。
